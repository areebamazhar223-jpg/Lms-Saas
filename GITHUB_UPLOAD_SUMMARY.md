## 💻 To Use This Code

### Clone Repository
```bash
git clone https://github.com/areebamazhar223-jpg/Lms-Saas.git
cd Lms-Saas
```

### Setup Backend
```bash
cd backend
npm install
npm run seed:admin  # Create admin account
npm run dev
# Backend runs on http://localhost:5000
```

### Setup Frontend
```bash
cd frontend/lms-saas
npm install
npm run dev
# Frontend runs on http://localhost:5174
```
