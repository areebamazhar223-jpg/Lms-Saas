## 🎨 DESIGN FEATURES

### Color Scheme
```css
/* Primary Colors */
Beige:        #eadcc8  /* Backgrounds, borders */
Olive Green:  #858e47  /* Primary actions, headers */
Orange:       #df8739  /* Accent, CTAs */

/* Additional */
White:        #ffffff  /* Cards, content */
Dark Text:    #1a1a1a  /* Primary text */
Gray:         #666666  /* Secondary text */
```

### Typography
- **Headings**: Poppins/Inter, Bold (700)
- **Body**: Poppins/Inter, Regular (400)
- **Labels**: 10px - 14px, Uppercase, Spaced
- **Responsive**: clamp() for fluid sizing

### Animations
- Hover effects with 3D transforms
- Smooth transitions (0.3s ease)
- Loading spinners
- Fade-in animations
- Stagger animations

### Responsive
- Mobile-first approach
- Breakpoints: 320px, 480px, 768px, 1024px, 1440px, 2560px
- Flexible grids
- Touch-friendly (minimum 44px touch targets)
