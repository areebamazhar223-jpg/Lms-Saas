## 💻 To Use This Code

### Clone Repository
```bash
git clone https://github.com/areebamazhar223-jpg/Lms-Saas.git
cd Lms-Saas
```

### Local Development

**Backend**:
```bash
cd backend
npm install
npm run seed:admin  # Create admin account
npm run dev
# Backend: http://localhost:5000
```

**Frontend**:
```bash
cd frontend/lms-saas
npm install
npm run dev
# Frontend: http://localhost:5174
```
